# Diet Planner Application

A Streamlit web application that plans meals based on daily budget, calorie targets, and dietary preferences (Vegetarian / Non-Vegetarian).

## Prerequisites

Python is required along with the following packages listed in `requirements.txt`:
- `streamlit`
- `pandas`

## How to Run

1. Open your terminal in this directory (`d:\diet_planner`).
2. Run the application using Streamlit:

```bash
streamlit run diet.py
```

or using Python module execution:

```bash
& "C:\Users\LENOVO\AppData\Local\Python\bin\python.exe" -m streamlit run "d:\projects\diet_planner\diet.py"
```

3. Alternatively, on Windows, double-click or run `run.bat`.
